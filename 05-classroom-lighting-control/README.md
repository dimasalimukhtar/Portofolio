# Schedule-Based Classroom Lighting Control System

## 1. Project Overview

This project focuses on the development of a schedule-based classroom lighting control system using an ESP32 microcontroller and a web dashboard.

The system is designed to support scheduled lighting operation and centralized monitoring through a web-based interface. The project addresses the application of embedded systems and automation in university classroom environments.

## 2. Project Objectives

- Develop a schedule-based classroom lighting control system.
- Implement lighting control using an ESP32 microcontroller.
- Provide a web dashboard for system monitoring and interaction.
- Explore the application of automation in university building lighting.
- Document the system architecture and implementation for engineering evaluation.

## 3. System Architecture

The system combines an embedded controller with a web-based interface.

The main components are:

| Component | Function |
|---|---|
| ESP32 | Embedded control and system execution |
| Lighting control hardware | Switching or controlling classroom lighting |
| Web dashboard | User interface for monitoring and interaction |
| Scheduling logic | Supports time-based lighting operation |

The final architecture and communication details will be documented according to the implemented system.

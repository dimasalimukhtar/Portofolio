# MICHINE — Microgreen Monitoring and Automatic Watering System

## 1. Project Overview

MICHINE is a microgreen monitoring and automatic watering system developed to support the monitoring of growing conditions and automated watering operations.

The project integrates an ESP32-based controller with environmental and distance sensors, a real-time clock, LoRa communication, and Firebase for data monitoring.

The system demonstrates the application of embedded systems, sensor integration, wireless communication, and IoT technologies in agricultural automation.

## 2. Project Objectives

- Monitor environmental conditions during microgreen cultivation.
- Integrate sensors with an ESP32-based controller.
- Support automatic watering based on the implemented control logic.
- Enable data communication and remote monitoring.
- Evaluate the performance of selected sensors and system components.

## 3. System Architecture

The system uses the following main components:

| Component | Function |
|---|---|
| ESP32 | Main embedded controller |
| DHT22 | Temperature and relative humidity measurement |
| Ultrasonic sensor | Distance measurement for the implemented monitoring function |
| Real-Time Clock (RTC) | Timekeeping and schedule support |
| LoRa | Wireless communication |
| Firebase | Data storage and remote monitoring integration |

The detailed data flow and control logic will be documented according to the final implementation.

## 4. System Features

The project focuses on:

- Environmental monitoring.
- Sensor integration with an ESP32 controller.
- Time-based system operation using an RTC.
- Wireless data communication using LoRa.
- Firebase integration for remote data monitoring.
- Automatic watering functionality.

| DHT22 humidity — serial output | 94.49% |

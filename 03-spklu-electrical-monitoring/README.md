# Off-Grid SPKLU Electrical Monitoring System

## 1. Project Overview

This project focuses on the implementation of an electrical monitoring system for an off-grid Electric Vehicle Charging Station (SPKLU). The system is intended to monitor key electrical parameters to support installation verification, operational observation, and electrical performance evaluation.

The project was carried out as part of an electrical engineering project involving the installation of an off-grid SPKLU system at BBPVP Bandung.

## 2. Project Objectives

- Monitor electrical voltage and current.
- Measure electrical power and energy consumption.
- Support electrical installation testing and monitoring.
- Evaluate the operation of the electrical monitoring system across three charging stations.

## 3. System Scope

The project scope includes:

- Electrical monitoring for three charging stations.
- Integration of PZEM-004 electrical measurement modules.
- Measurement of voltage, current, power, and energy.
- Installation and functional testing of the monitoring system.

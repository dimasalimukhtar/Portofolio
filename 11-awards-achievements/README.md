## 1. Gold Medal — NICYMS 2024

**Project:** LoRa Drip Irrigation System for Mustard Greens

**Recognition:** Gold Medal

**Competition:** National Innovation and Creativity Youth Management Student (NICYMS) 2024

### Overview

The achievement was associated with a LoRa-based drip irrigation project developed for mustard greens cultivation.

The project explored the integration of wireless communication and irrigation technology for agricultural applications.

### Project Highlights

- Drip irrigation system development.
- Application of LoRa wireless communication.
- Integration of electronic control components.
- Engineering project implementation and documentation.

**Project:** MICHINE — Microgreen Monitoring and Automatic Watering System
